\begin{abstract}
React has become the most widely used web front-end framework, enabling the creation of graphical user interfaces in a declarative and compositional manner.
Hooks are a set of APIs that manage side effects in function components in React.
However, their semantics are often seen as opaque to developers, leading to UI bugs.

We introduce \Rtrace, the first formal operational semantics of the essence of React Hooks.
We demonstrate that our model captures the behavior of React, by theoretically showing that it embodies essential properties of Hooks and empirically comparing our \Rtrace-definitional interpreter against a test suite.
Furthermore, we showcase a practical visualization tool based on the formalization to demonstrate how developers can better understand the semantics of Hooks.
\end{abstract}

\begin{abstract}[ko]
오늘날 \alt{웹 앞단}{web front-end}을 만드는 데 가장 널리 쓰이는 \alt{개발 틀}{framework}인 \alt{리액트}{React}는, \alt{사용자 화면}{graphical user interface, GUI}을 조립식으로 선언하여 만들 수 있게 해 준다.
\alt{훅}{Hook}은 리액트의 함수형 \alt{화면 부품}{component}에서 \alt{부수 효과}{side effect}를 관리하는 API 모음이다.
그러나 개발자들은 훅의 동작 방식을 제대로 모르는 경우가 많아, 화면을 그릴 때 오류가 발생하곤 한다.

우리는 리액트 훅의 핵심을 처음으로 담아낸 엄밀한 \alt{실행 의미구조}{operational semantics}인 \Rtrace를 제시한다.
우리 모델이 리액트의 실제 동작을 잘 담아낸다는 것을 보이기 위해, 훅의 중요한 특성을 만족함을 이론적으로 증명하고, \Rtrace를 \alt{구현한 실행기}{definitional interpreter}를 \alt{테스트 모음}{test suite}과 실험적으로 비교한다.
나아가 우리는 개발자가 훅을 더 잘 이해할 수 있도록, 엄밀한 의미구조를 바탕으로 실용적인 시각화 도구를 개발하였다.
\end{abstract}

\chapter*{감사의 말}
\addcontentsline{toc}{chapter}{감사의 말}
먼저 학부 인턴 시절부터 지금까지 4년간 지도해주신 이광근 교수님께 깊은 감사의 말씀을 드립니다.
교수님께 학부 프로그래밍 언어 수업을 들은 2019년 가을, 저는 제가 오랫동안 찾아 헤매던 보물섬을 발견했습니다.
본인이 직접 겪은 문제를 해결하라는 교수님의 가르침 덕에, 정말 물 흐르듯 제가 관심있는 연구 주제에 도달할 수 있었습니다.
엄하실 땐 엄하시지만, 누구보다도 학생들 곁에서 가깝고 따뜻하게, 그리고 열정적으로 지도해주셔서 감사드립니다.
교수님 덕분에 OCaml 프로그래밍 언어를 접하고, 평양냉면의 맛을 배우고, \qty{10}{km} 달리기를 완주했습니다.
교수님 덕분에 진정한 연구자와 교육자의 모습을 알게 되었습니다.
앞으로도 교수님께 배운 것들을 잊지 않고 즐겁게 수학하고 연구하겠습니다.

프로그래밍 언어 연구실에서 함께 지내며 수학한 동료들에게도 감사드립니다.
리액트 연구 후반에 큰 도움을 준 중원이가 아니었다면 제 때 논문을 작성하기 어려웠을 것입니다.
특히 중원이는 (학위 논문에는 담지 않았지만) 이후에도 리액트 합성 연구, 분석기 재활용 연구도 함께 진행한, 정말 든든한 후배입니다.
그리고 학부 인턴 시절과 석사 초반을 함께한 전기과 동기 준협이에게도 정말 고맙습니다.
준협이와 함께 학교를 등산하며 나누었던 프로그래밍 언어 연구 이야기, 그리고 연구의 진행이 더딜 때 주었던 응원이 아니었다면 연구실 생활이 힘들었을 것입니다.
연구 외적으로도 많은 이야기를 나누며 연구실에 활력을 불어준 규혁, 민정, 형서 누나, 원준, 인호에게도 너무나 고맙습니다.
소중한 연구실 동료 선후배들 덕에 매일이 즐거웠습니다.

대학 생활을 하면서 언제나 따뜻하게 반겨주시고 진심 어린 조언과 격려를 해주신 최형규 교수님께 깊은 감사의 말씀을 드립니다.
제가 교수님의 공학 수학 수업을 정리한 \LaTeX{} 강의노트가 이렇게 소중한 인연과 큰 복으로 다가올 줄은 몰랐습니다.
저에게 즐거운 수학 이야기를 해주시고, 스키를 태워주시고, 한국텍학회에 소개해주셔서 감사드립니다.
공학 수학 교수님을 넘어 삶의 선생님이 되어주셔서 감사드립니다.

저에게 \TeX의 미학과 즐거움을 가르쳐주신 한국텍학회 김강수 선생님과 조인성 교수님께 감사의 말씀을 드립니다.
두 분의 가르침 덕분에 부끄럽지 않게 조판된 논문을 완성할 수 있었습니다.
나아가 \TeX에서 한글로도 아름다운 문서를 조판할 수 있게 힘써주셔서 감사드립니다.

대전에 내려갈 때마다 한결같이 저를 반겨주는 10년지기 친구 용훈이, 그리고 한국과학영재학교 동기들에게도 고맙습니다.
길게 말하지 않아도 마음이 통하는 친구를 찾아 행운입니다.
고등학교를 졸업한 후에도 각자의 자리에서 묵묵하지만 치열하게 과학의 발전을 위해 힘쓰는 제 친구들에게 항상 위로받고, 또 자극받습니다.

언제나 기쁜 일이 있을 때는 저보다 더 기뻐해주고, 힘들고 지칠 때 제 마음의 휴식처가 되어준 여자친구 수지에게도 고마운 마음을 전합니다.
특히 수지는 \cref{fig:vis}의 멋있는 \Rtrace{} 로고도 직접 만들어주었습니다.
이해할 수 없는 연구 이야기를 하는 저를 항상 귀기울여 잘 들어주어서 너무 고맙습니다.

마지막으로 제가 걱정없이 학교 생활을 할 수 있도록 물심양면으로 힘써 주시고 믿어주신 부모님께 감사드립니다.
실험실에서 연구하고 논문 쓰는 과학자 아빠를 보면서 자랐지 않았더라면, 제 교육에 힘써주시고 어린이날에 과학책을 사주신 엄마가 아니었다면 지금의 저는 없었을 것입니다.
그 동안 고집세고 제멋대로인 저를 키워주신 엄마, 아빠께 감사드립니다.
